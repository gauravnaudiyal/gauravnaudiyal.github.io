Real Time Rendering with OpenGL

Weekly assignments where I built rendering techniques from the ground up using C++ and OpenGL.

What it is

Every week added a new piece on top of what I already had, going from basic shapes on screen to lighting, shading, and more advanced rendering steps by the end of the module.

What I worked on

  • Built the rendering pipeline step by step in C++
  • Implemented lighting models and wrote my own shaders
  • Got a much better feel for how the GPU pipeline actually works under the hood

What I learned

Rendering is one of those topics that sounds abstract until you actually write the code yourself. Once I built the pipeline stage by stage, concepts I only knew in theory finally clicked.
