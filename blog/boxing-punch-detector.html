Boxing Puncher Detector

A side project that detects boxing stance and flags punch candidates using MediaPipe and OpenCV.

What it is

I box, so this one came from an actual hobby rather than a class assignment. I got the idea from an app called Jabbr and wanted to see if I could build something similar myself. It uses pose detection to figure out if someone's in a boxing stance and whether a movement looks like a punch.

What I worked on

  • Used MediaPipe to track body pose in real time from webcam input
  • Wrote logic to classify stance and detect punch candidates from the keypoints
  • Tested it on live footage of myself training to see how accurate it was

What I learned

Pose detection libraries handle a lot of the hard work, but turning raw keypoints into something meaningful like "that's a jab" takes a lot of trial and error.
