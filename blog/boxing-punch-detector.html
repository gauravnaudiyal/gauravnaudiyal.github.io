Boxing Puncher Detector

A side project that detects boxing stance and classifies punch candidates using MediaPipe and OpenCV.

Overview

I box, so this one was personal. The idea came from Jabbr — I wanted to see if I could build something that detects whether someone is in a boxing stance and flags a potential punch using pose estimation. Built in Python with MediaPipe and OpenCV.

What I worked on

  • Used MediaPipe for real-time pose landmark detection
  • Built logic to classify stance and punch candidates from keypoint positions
  • Tested on live webcam input and recorded footage
