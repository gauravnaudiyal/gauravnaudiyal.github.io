VR Haptics Project

Exploring tactile feedback and interaction design in VR.

Overview

This is my dissertation project, built in Unity with the bHaptics SDK to test how tactile feedback changes the way people experience a VR scene.

What I worked on

  • Designed interaction flow in Unity
  • Integrated haptic feedback patterns tied to in-scene events
  • Ran early tests to see how feedback timing changes immersion
