VR Haptics Project

This is my dissertation project, testing how haptic feedback changes the way people feel presence in VR.

What it is

I built a VR simulation in Unity and connected it to bHaptics hardware so users get physical feedback while doing tasks in the headset. The main question I'm trying to answer is whether adding haptics actually makes a scene feel more real, or if it just adds noise.

What I worked on

  • Set up the VR scene in Unity and got it running on Quest
  • Integrated the bHaptics SDK and mapped feedback patterns to in game events
  • Ran early tests with a few users to see how they reacted to different feedback timing

What I'm still figuring out

The tricky part is timing. If the haptic feedback fires slightly late it feels disconnected from what's happening on screen. I'm still tuning this before the final round of testing.
