SQL Data Job Analysis

Using SQL to dig into job posting data for data roles, built to get more comfortable writing real queries.

What it is

I wanted a project that used SQL outside of just coursework, so I picked a dataset of data job postings and started asking questions with it. Things like which skills show up most, and how salaries compare across roles.

What I worked on

  • Wrote queries to break down job postings by role, location, and salary
  • Looked at which skills came up most often across different job titles
  • Practiced joins and aggregations on a dataset that actually meant something to me

What I learned

SQL feels a lot more useful once you're asking your own questions instead of following a set assignment. This project made the syntax stick a lot better than just memorizing it.
