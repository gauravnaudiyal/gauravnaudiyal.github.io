SQL Data Job Analysis

Using SQL to analyse job market data for data roles — built as a practical project to sharpen SQL skills.

Overview

A project using SQL queries to explore a dataset of data job postings, looking at demand, salaries, and skills. Straightforward but useful — it made SQL feel practical rather than just academic.

What I worked on

  • Wrote queries to slice job data by role, location, and salary
  • Looked at which skills appear most frequently across postings
  • Used it as a way to get more comfortable with SQL outside of coursework
