Screen Space Rendering

A focused project on screen space rendering techniques, written up properly in a report.

What it is

This project looked at how post processing effects get applied to a scene after the main render pass. I wrote a full report explaining the reasoning behind each technique, which lives in the repo along with the code.

What I worked on

  • Implemented screen space effects in C++
  • Wrote a detailed report explaining how and why each technique works
  • Tested the effects across different scenes to check they held up

What I learned

Screen space techniques are a good example of getting a lot of visual quality without redoing the whole scene. It's a smart shortcut once you understand where it applies.
